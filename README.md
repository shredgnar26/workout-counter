Training Counter

A static HTML training timer and counter app with persistent browser memory.

Features

Simple stopwatch

EMOM timer with configurable rounds, round length, and countdown

HIIT timer with configurable work/rest intervals, rounds, and countdown

Up to 10 concurrent trackers

Daily counter with customizable reset time

Weekly counter with customizable reset day and time

Lifetime total

Browser-local persistence with localStorage for counters and timer settings

Missed reset catch-up when the app is reopened

Deploy

Push this folder to GitHub, then import the repo into Vercel.

Vercel settings:

Framework Preset: Other

Build Command: leave blank

Output Directory: leave blank

The app entry point is index.html.
